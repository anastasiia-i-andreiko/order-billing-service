# Release Notes — v1.1.0

## Added
- Додано спеціальний базовий тариф доставки **80.0** для міста **Kyiv**.
- Додано явний параметр ставки податку `tax_rate` (зі значенням за замовчуванням `0.20`) у функцію розрахунку стандартного рахунку.

## Changed
- Збільшено коефіцієнт вартості доставки за вагу з `12.0` до `15.0` за 1 кг.
- Виконано рефакторинг модуля `billing.py`: здійснено перехід від високої міжмодульної зв'язності (Common, Stamp, Control Coupling) до еталонного **Data Coupling**.

## Breaking Changes
- **Змінено сигнатури функцій:** функції розрахунку тепер приймають примітивний параметр `city: str` замість цілого об'єкта `CustomerProfile`.
- **Видалено глобальний стан:** прибрано глобальну змінну `GLOBAL_TAX_RATE`.
- **Видалено прапорець керування:** прибрано параметр `mode_flag` та загальну функцію `process_invoice` — замість неї необхідно використовувати окремі функції `process_standard_invoice()` та `process_tax_exempt_invoice()`.
